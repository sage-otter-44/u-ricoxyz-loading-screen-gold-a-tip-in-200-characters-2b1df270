Entry for the [make.fun](https://make.fun) bounty "Loading Screen Gold: A Tip in 200 Characters" — one sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer.

## Entry

> Tip: your agent just re-read the same file for the fifth time. It's not stuck — it's doing what you do in standup: stalling, and calling it thinking.

## How it works

`main.ts` builds the tip from three beats (setup, turn, punchline), validates it (1–200 characters, single line, no surrounding whitespace), and writes it to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```
